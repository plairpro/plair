# PLAIR — документация проекта

Этот раздел описывает весь сайт **plair.pro**: где что лежит, как работает лента игр, сервер, подсчёты и как всё это выкладывать. Он написан так, чтобы проект мог подхватить разработчик команды вручную или другая нейросеть — без доступа к истории переписки.

Состояние на 21 октября 2026 года.

## Пять фактов, которые нужно знать сразу

1. **Сайт — чистый статический HTML/CSS/JS без сборки**, лежит в репозитории `plairpro/plair` и публикуется GitHub Pages из ветки `main`. Любой коммит в `main` через 1–2 минуты на сайте.
2. **Всё «живое»** (счётчики, лайки, комментарии, вход, сохранения, заявки игр, рекорды) — это один Cloudflare Worker `plair-counts` с базой D1. Его код — `worker/src/worker.js`. Выкладывается **отдельно**: `npx wrangler deploy` из папки `worker/`.
3. **После правки `games/games.js` или `games/games.css` нужно поднять версию** в `index.html` (`games.js?v=53` → `?v=54`), иначе браузеры возьмут старый файл из кэша.
4. **Секретов в репозитории нет и быть не должно** (кроме известной проблемы с ботом формы — см. OPERATIONS.md, «Риски»). Секреты Worker’а хранятся в Cloudflare.
5. **Игры не хранятся у нас.** Каталог — это ссылки на чужие страницы (GitHub Pages и др.), которые открываются в `<iframe>`.
