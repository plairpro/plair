# Лента PLAIR Games (`/`)

Главная страница — `index.html` + `games/games.js` + `games/games.css` (+ общий `styles.css`). Весь интерфейс на английском.

## Что видит игрок

- **Шапка** (`.g-top`, фиксирована поверх ленты): логотип `.g-brand` (клик — сброс в ленту по умолчанию), поиск `#q`, кнопка «i» `#how` (как всё устроено), аккаунт `#who`, зелёный «+» `#submit-open` (добавить игру).
- **Фильтры** `#filters`: сортировка **New / Popular** (и **Saved** у вошедших), жанры-чипы.
- **Лента** `#feed` (`.g-deck`): вертикальная, один экран — одна игра (`scroll-snap`). Карточка `.g-slide`:
  - обложка (`.g-shot`) + два размытых задника (`.g-back` на весь экран, `.g-fill` внутри колонки);
  - кнопка Play по центру (`.g-go`);
  - подпись `.g-info`: название, описание в одну строку (тап — раскрыть), жанры в строку (не влезшие — под «+N»);
  - строка автора `.g-meta`: `@автор` (+ зелёная галочка, если автор подтверждён), справа значки с числами: ▶ запуски, ♥ лайки, 💬 комментарии, 🔖 сохранения, «поделиться».
- **Проигрыватель** `.g-player` (во весь экран, поверх всего, `z-index:80`): шапка с названием, кнопками «кубок» (таблица рекордов, если игра подключила SDK), «во весь экран», «поделиться», закрыть; ниже `<iframe>` с игрой.
- **Панели** `.g-sheet` (z-index 60, ниже проигрывателя): «i», «+», аккаунт, комментарии, модерация.

## Устройство `games/games.js`

Один IIFE в стиле ES5 (без модулей и сборки). Разделы помечены комментариями `/* ── название ── */`:

| Раздел | Что делает |
|---|---|
| начало файла | константы: `TAGS` (20 жанров), `CATALOG` (`/games/games.json`), `COUNTS` (адрес Worker’а), `SORTS`, `START` (параметры адреса при загрузке) |
| счётчики (до «лента») | `visitor()` — случайный номер браузера; `countPlay`, `countShare`, `ping` (sendBeacon), время в игре (`clock*`), скип (`countSkip`), `loadCounts`, формула `score()` и веса `WEIGHT` (см. RANKING.md) |
| запросы к GitHub | `gh()` и кэш — **остаток старой формы добавления, сейчас не используется**, можно удалить |
| лента | `slideHTML`, `renderFilters`, `renderFeed`, `fitTags` (жанры в строку), `softBacks` (размытие задников один раз в canvas), `warm` (подгрузка соседних обложек) |
| панели | `sheet()`, `shut()` |
| инструкция | `howSheet()` — окно «i»: правила для авторов, лимиты, SDK, как упорядочена лента; `weighGame()` — подсчёт веса игры; пределы `LIMIT_MB=10`, `LIMIT_SEC=10` |
| связаться | форма «Contact us» → Telegram (настройки из `window.PLAIR_CONFIG` в `content.js`) |
| добавить игру | `submitSheet`, `inspectGame` (читает страницу игры, ищет обложку), `checkOwner`/`drawOwn` (подтверждение авторства), `githubByCode` (вход GitHub по коду), `drawWeight`, `ownCover` (своя обложка → canvas 720×1280), `sendGame` |
| аккаунт | `accountSheet`, `drawWho` (аватар в шапке, зелёная точка — есть заявки на модерацию) |
| модерация | `reviewSheet`, `drawReview` (вес, способ подтверждения), `decideGame` (Publish / Skip) |
| поделиться | соцсети `NETS`, `shareURL(g)` = `https://plair.pro/?g=<id>`, копирование, Instagram |
| комментарии | `api()` (fetch к Worker’у с пропуском), `loadMe`, `loadCfg`, вход Google (`googleButton`, `onGoogle`), `talkSheet` |
| лайки | `liked` (localStorage), `toggleLike`, `drawLike`; `numHTML`/`drawNums` — числа под значками |
| избранное | сохранения (`toggleSave`, только для вошедших), PLAIR-листы (`openList`, `shareMyList`) |
| запуск игры | `play(g, opts)` — создаёт проигрыватель и `<iframe sandbox>`, засчитывает запуск, запускает таймер; `quit()` |
| рекорды (PLAIR SDK) | приём `postMessage` от игры, `sdkScore`, `guestScore`, `flushScores`, `showBoard`, `makeDuel`, `openDuel` (см. SDK.md) |
| события | общий обработчик кликов, клавиатура (стрелки, Enter, Esc), прокрутка (раз в кадр), `popstate`, `pagehide` |
| поиск | `fold()` (без регистра и диакритики), поиск по названию, старому русскому названию `aka`, id, жанрам, описанию, автору |
| старт | `fetchGames()` (каталог + одобренные заявки с сервера), `reloadGames`, `goHome`, загрузка входа, счётчиков, обработка параметров адреса |

## Откуда берутся игры

`fetchGames()` склеивает два источника:

1. `games/games.json` — каталог, правится руками (игры студии).
2. `GET /games` на Worker’е — заявки авторов, одобренные модератором.

При совпадении `id` побеждает каталог. Список сортируется по дате `added`.

Поля игры (в `games.json` и в ответе `/games`):

| Поле | Обязательно | Смысл |
|---|---|---|
| `id` | да | латиница, цифры, дефис, до 40 символов; уникален |
| `title` | да | название (англ.) |
| `aka` | нет | старое/русское название — только для поиска |
| `blurb` | нет | одна строка описания |
| `tags` | нет | жанры из `TAGS` |
| `cover` | нет | путь к обложке 9:16 (`/games/covers/<id>.webp`) или URL |
| `url` | да | адрес игры (https), открывается в iframe |
| `repo`, `by`, `byUrl` | нет | репозиторий и автор (`by` — ник, `byUrl` — ссылка на автора) |
| `added` | да | дата `YYYY-MM-DD`, по ней «New» |
| `verified` | нет | `true` — зелёная галочка у автора |

## Параметры адреса

Читаются один раз при загрузке (`START`), затем адрес очищается до `/` — обновление страницы всегда ведёт в ленту по умолчанию (все игры, «New»).

| Параметр | Что делает |
|---|---|
| `?g=<id>` | лента встаёт на эту игру (так выглядят ссылки «поделиться»); при открытой игре адрес временно `?g=<id>` |
| `?g=<id>&c=1` | плюс открыть комментарии (возврат после входа) |
| `?q=<текст>` | поиск |
| `?list=<код>` | открыть чей-то PLAIR-лист |
| `?review=1` | открыть очередь модерации (ссылка из Telegram) |
| `?add=<url>` | открыть форму «+» с этой ссылкой (возврат после входа через GitHub) |
| `?g=<id>&duel=<код>` | вызов «побей мой рекорд» от друга |
| `#play-<id>` | старый формат ссылок, поддерживается |

## Хранилище браузера

| Ключ | Где | Что |
|---|---|---|
| `plair-visitor` | localStorage | случайный номер браузера (24 hex), по нему лимиты счётчиков |
| `plair-session` | localStorage | пропуск входа (подписан сервером, 180 дней) |
| `plair-liked` | localStorage | какие игры лайкнул этот браузер |
| `plair-plays` | localStorage | сколько раз сегодня засчитан запуск каждой игры (до 10) |
| `plair-shared`, `plair-skipped` | localStorage | репост / скип уже засчитан сегодня |
| `plair-score-hint` | localStorage | подсказка про рекорды уже показана |
| `plair-pending-scores` | sessionStorage | лучший счёт гостя до входа — отправится после входа |
| `plair-draft-<id>` | sessionStorage | черновик комментария |
| `plair-order` | — | устарел, при загрузке удаляется |

## Производительность (важно для iPad и слабых устройств)

- Размытые задники карточек **не используют CSS `blur()`**: `softBacks()` один раз уменьшает обложку в canvas, запекает насыщенность/яркость и подставляет как data-URL. Живой `blur()` — только запасной путь (`.is-live`), если обложку нельзя прочитать (чужой сервер без CORS).
- Никакого `backdrop-filter` над листающейся лентой (кроме минимально необходимого).
- Обработчик прокрутки — не чаще раза за кадр (`requestAnimationFrame`).
- `.g-slide` имеет `contain: layout paint`.
- При закрытии игры кадр сначала получает `src=about:blank`, затем удаляется — иначе звук доигрывает.
