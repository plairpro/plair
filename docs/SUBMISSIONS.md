# Добавление игры автором

Форма — зелёный «+» в шапке (`submitSheet` в `games/games.js`), правила — окно «i» (`howSheet`). Сервер — `POST /verify`, `POST /submit` (`worker/src/worker.js`).

## Шаги для автора

1. Вставить ссылку на игру. Принимается любой https-адрес; ссылка на репозиторий `github.com/имя/проект` превращается в `имя.github.io/проект/`.
2. Страница сама читает игру (`readPage`, нужен CORS — у GitHub Pages он есть): название (`og:title`/`<title>`), описание (`og:description`), обложку. Обложка ищется так: `cover.webp`, `cover.png`, `cover.jpg`, `cover.jpeg` рядом с игрой, затем `og:image`. Можно загрузить свою — она ужимается в браузере до 720×1280 webp/jpeg < 440 КБ.
3. **Вес игры** считается автоматически (`weighGame`): см. ниже. Больше 10 МБ — кнопка отправки неактивна.
4. **Подтверждение авторства** (блок «Show it’s yours») — обязательно.
5. Необязательно: жанры (до 5), контакт, PLAIR SDK для рекордов (блок «Scores and challenges»).
6. «Send for review» → заявка в очередь, уведомление модератору в Telegram со ссылкой `https://plair.pro/?review=1`.
7. Модератор нажимает Publish — игра сразу в ленте сверху (по дате одобрения).

## Вес (лимит 10 МБ)

Константы: `LIMIT_MB = 10` (браузер), `MAX_WEIGHT` (сервер, 10 МБ). Рекомендация в правилах — до 5 МБ и играбельно за 10 секунд на 4G.

Как считается (`weighGame` в браузере автора):

- загружается страница игры, затем все `<script src>`, стили, `preload/modulepreload`, `<img>/<audio>/<video>/<source>`;
- в тексте страницы, скриптов и стилей ищутся пути к файлам с расширениями ассетов (js, css, wasm, data, unityweb, glb, gltf, bin, картинки, звук, видео, json, шрифты и др.), в том числе сборки Unity (`.data.br`, `.wasm.br`);
- размер каждого файла — из `Content-Length` (то есть сжатый, как идёт по сети) через `HEAD`; если заголовка нет — файл читается целиком;
- в коде считаются только адреса того же сайта; чужие — только если подключены тегами;
- шрифт, данный в нескольких форматах, считается один раз (woff2);
- до 150 файлов и 25 секунд; при превышении лимита подсчёт останавливается.

Это оценка «всё, на что игра ссылается», а не точная первая загрузка: файлы, которые игра грузит по ходу, тоже учитываются. Если сайт игры не даёт себя прочитать (нет CORS), вес — «unknown», модератор проверяет вручную.

Сервер принимает вес от страницы (`body.weight`) и отказывает (`413 heavy`), если он больше лимита. Вес виден модератору и в уведомлении.

## Подтверждение авторства

Прислать можно только свою игру. Сервер (`proveOwner`) принимает одно из:

| Способ | Как работает |
|---|---|
| **Вход через GitHub** | игра на `имя.github.io/…`, автор вошёл как `имя`; для страниц организаций (`team.github.io`) — если автор **открыто** состоит в организации (GitHub API `public_members`). Кнопка «Sign in with GitHub» видна только для адресов `*.github.io` |
| **Код на странице** | форма выдаёт строку `<meta name="plair-verify" content="plair-xxxxxxxxxxxx">`; её кладут в `<head>` `index.html` игры **или** файл `plair.txt` с кодом рядом с `index.html`. Сервер скачивает страницу (мимо кэша GitHub Pages) и ищет код |
| **Модератор** | заявки модераторов не проверяются |

Код = `plair-` + 12 hex от HMAC(секрет Worker’а, «verify|» + адрес папки игры). Он стабилен для одной игры (`/game/` и `/game/index.html` дают один код) и не подбирается без секрета.

Способ подтверждения сохраняется в `submissions.proof` и виден модератору.

## Галочка «Verified author»

Зелёная галочка у `@автор` на карточке:

- игры каталога — поле `"verified": true` в `games/games.json` (все игры `plairpro`);
- игры авторов — `verified`, если заявка подтверждена через GitHub или кодом (не модератором).

## Модерация

Аватар в шапке у модератора с зелёной точкой — есть заявки. Аккаунт → «Review new games»: превью обложки, название, ссылка, вес, способ подтверждения, контакт. Кнопки: **Try** (открыть в проигрывателе), **Publish**, **Skip**.

Снять одобренную игру — `POST /submissions/:id {action:'unpublish'}` (из интерфейса пока нет) или в базе:

```sh
npx wrangler d1 execute plair-counts --remote --command "UPDATE submissions SET status='rejected' WHERE game='slug'"
```

## Добавить игру студии вручную (без формы)

1. Положить обложку 720×1280 в `games/covers/<id>.webp`.
2. Добавить объект в начало `games/games.json` (поля — см. FEED.md), `"verified": true`.
3. Коммит в `main`. Версию `games.js` поднимать не нужно — каталог грузится без кэша.
